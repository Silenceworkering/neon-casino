# Проверка реализации

Дата: 15 октября 2026. Локальная Linux-среда, Node.js 24.19.0, PostgreSQL 18.4, системный Chromium.

- TypeScript и production-сборка Vite/esbuild: успешно.
- 19 автоматических проверок: игровой движок, HTTP API на настоящей PostgreSQL и Socket.IO с настоящими клиентами.
- Все 18 одиночных режимов начинают и завершают раунд через API; каждый результат сохраняется.
- Проверены идемпотентные параллельные ставки, однократные выплаты/бонусы, глобальный лимит промокода, защита от отрицательного баланса и изменений баланса через API.
- Проверены секретные состояния, доступ только к своему раунду, права администратора и журнал начислений.
- Реальные комнаты Battle, Jackpot и Draw Poker: общий банк сохраняется, повтор старта не списывает ставку снова, переподключение работает.
- Draw Poker на шесть клиентов: обмен всех карт и перемешивание сброса не создают дубликаты и не теряют валюту.
- Турнир выплачивает награду один раз. Восстановление пароля меняет код и отзывает HTTP/WebSocket-сессии.
- Chromium: регистрация, игра, профиль, настройки, daily bonus и reload. Ширины 320 / 375 / 390 / 768 / 1024 / 1440 без горизонтального overflow; JS page errors отсутствуют.
- Отдельно выполнен реальный останов и запуск процесса Node: cookie-сессия, кошелёк и активный Mines сохранились. Локальная PostgreSQL также была перезапущена во время проверки.
- `npm audit --omit=dev`: 0 известных уязвимостей после обновления транзитивных deepmerge-ts/effect.
- `.env` не отслеживается Git. В коде нет Math.random для результатов, TODO/FIXME или dangerouslySetInnerHTML.

Скриншоты: `artifacts/home-desktop.png`, `artifacts/home-mobile.png`, `artifacts/game-mobile.png` (локальные артефакты, не входят в Git).

Это не подтверждение промышленной эксплуатации. Не проверены физические iPhone/Android, длительная нагрузка, восстановление внешнего backup, реальные GitHub push/Render deployment, актуальные тарифы провайдеров. Ограничения функциональности перечислены в README. Нет публичной ссылки Render: сервис не создавался, внешняя база не подключалась.

В данной среде хост binaries.prisma.sh запрещён сетевой политикой. Для генерации клиента, который использует официальный JS PostgreSQL adapter и не исполняет нативные query binaries, использовались локальные переменные `PRISMA_SCHEMA_ENGINE_BINARY=/bin/true PRISMA_QUERY_ENGINE_LIBRARY=/bin/true`. Нативные query binaries в выбранной архитектуре не исполняются; этот шаг не проверяет применение миграций. SQL миграции действительно применены к PostgreSQL, затем проверены интеграционными тестами. Нативный `prisma migrate deploy` в этой среде не проверен из-за недоступности скачивания; на Render он должен выполняться стандартной командой при доступном binaries.prisma.sh.
